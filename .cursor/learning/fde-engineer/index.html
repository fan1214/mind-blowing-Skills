学习路径 预计 14 周

FDE 工程师（Forward Deployed Engineer）

在客户现场用代码与数据解决真实业务问题，并清晰沟通价值

6模块
4核心
80h预计学时

能力目标

  • 用 Python + SQL 快速探索、清洗并整合客户数据
  • 设计并实现 数据管道（采集 → 清洗 → 建模 → 交付），对接 REST API 与常见数据源
  • 在模糊需求下做 需求拆解，将业务问题转化为可交付的技术方案
  • 与客户、产品、工程多方协作，用 可量化结果 证明方案价值
  • 完成 2–3 个部署式端到端项目，展示快速学习与落地能力

学习里程碑

  1. 第 1–2 周：完成 M1 Python 基础，能写数据处理脚本
  2. 第 3–4 周：完成 M2 SQL，能在未知 schema 下做探索性分析
  3. 第 5–6 周：完成 M3 API 集成，能对接外部系统并写简单后端
  4. 第 7–8 周：完成 M4 数据管道，能设计并讲解集成架构
  5. 第 9–10 周：完成 M5 客户技能，能分解开放问题并做发现访谈
  6. 第 11–14 周：完成 M6 实战项目，整理作品集与演示材料

下一步

建议从这里开始

若你已有 Python 基础，可从 M2 SQL 开始；零基础请从 M1 Python 顺序学习。

学完某模块后，在对话中说「展开 M2」获取练习与自检题；全部模块学完后说「开始考试」进行结业测评。

本路径为自学规划参考，不构成任何公司官方认证或招聘承诺。FDE 岗位因公司与行业差异较大，请结合目标雇主 JD 微调侧重点。
