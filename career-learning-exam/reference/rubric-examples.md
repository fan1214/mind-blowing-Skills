# Rubric 与阅卷示例

主观题、简答题、代码题必须在 `exams/exam-{id}-rubric.md` 中附 Rubric（**不得**写入 HTML 试卷）。选择题只需标注正确答案与简要解析。阅卷结果写入 `results/result-{id}.html`。

## 简答题 Rubric 示例

```markdown
### Q5 (M3·中等·8分) [简答题]
**题目**：说明 Session 与 Cookie 的区别及各自典型使用场景。

**评分要点（共 8 分）**
- 存储位置：Session 服务端 / Cookie 客户端 (2)
- 生命周期与容量差异 (2)
- 各举 1 个合理使用场景 (2)
- 提及安全注意点（HttpOnly、HTTPS 等之一） (2)

**常见扣分**
- 仅罗列定义无场景 (-2)
- 混淆 Session ID 与 Session 数据存储 (-2)

**参考答案要点**
Session 存服务器，适合登录态；Cookie 存客户端，适合偏好/追踪；敏感信息勿明文放 Cookie…
```

## 代码题 Rubric 示例

```markdown
### Q12 (M4·进阶·10分) [代码题]
**题目**：用 PDO 查询用户表，按 id 获取单条记录，需防 SQL 注入。

**评分要点（共 10 分）**
- 使用预处理/占位符 (4)
- 正确绑定参数 (2)
- 错误处理或空结果处理 (2)
- 无拼接 SQL 字符串 (2)

**常见扣分**
- 用 mysql_* 或 mysqli 拼接 (-4)
- 无 prepare 仅有 quote (-2)

**参考代码要点**
$pdo->prepare('SELECT * FROM users WHERE id = ?'); bindValue; fetch; try/catch 可选
```

## 选择题规范

- 4 个选项，长度尽量接近（词数、字符数）
- 勿通过格式（加粗、长度）泄露答案
- 解析说明为什么错选项具有迷惑性

## 阅卷输出格式

```markdown
### Q5：6/8
- 得分：提到存储位置与场景 (+4)，未提安全 (-2)
- 解析：…

## 模块汇总
| 模块 | 得分 | 满分 | 得分率 | 核心 |
| M3 | 18 | 24 | 75% | ★ |

## 判定
- 总分：82/100
- M3 核心模块 75% ≥ 60% ✓
- 结论：**已通过**
```

## 补考 Rubric

补考只考失败模块时，满分按模块原占比折算（例如两模块占 40 分则补考卷 40 分，及格线仍为 80% 即 32 分），核心模块单项仍须 ≥ 60%。
